## 🧭 About Me

수식으로 현상을 이해하고, 그 이해를 실제 시스템에 적용하는 데 관심이 있습니다.
열전달·유체역학 문제를 수치해석으로 풀어보고, 감마 함수와 복소해석, 분수계 미적분 같은 이론을 공학 모델링에 연결하는 방법을 공부하고 있습니다.

최근에는 방위산업과 보안 분야로 관심을 넓혀, 방산수출 정책 연구와 소프트웨어·IoT 보안 취약점 분석을 비전공자의 시선에서 차근차근 익혀가는 중입니다.
