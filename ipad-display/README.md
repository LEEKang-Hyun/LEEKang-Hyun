# iPad Display — iPad를 Windows 노트북의 무선 듀얼 모니터로

같은 Wi-Fi에 있는 iPad의 **Safari만으로** Windows 화면을 띄우고, iPad 터치로 PC를 조작합니다.
iPad에는 앱을 설치할 필요가 없습니다.

```
[Windows 노트북]  server.py ──(Wi-Fi, WebSocket/JPEG)──▶  [iPad Safari]
   가상 모니터 캡처                                        화면 표시 + 터치 → 마우스
```

## 1. 확장 모드를 위한 가상 디스플레이 설치 (권장, 최초 1회)

Windows는 실제 모니터가 연결되어 있어야 "화면 확장"을 할 수 있습니다.
가상 디스플레이 드라이버를 설치하면 iPad를 **진짜 두 번째 모니터**처럼 쓸 수 있습니다.
(설치하지 않으면 노트북 화면을 그대로 보여주는 **복제 모드**로 동작합니다.)

1. GitHub에서 **Virtual Display Driver** (VirtualDrivers/Virtual-Display-Driver) 최신 릴리스의
   설치 프로그램을 받아 설치합니다.
2. `설정 → 시스템 → 디스플레이`에서 새 디스플레이가 보이면
   **"이 디스플레이 확장"**을 선택하고, 해상도를 iPad 비율에 맞춥니다.
   - iPad 대부분: **4:3** (예: 2048×1536, 1600×1200)
   - iPad Pro 11 / Air: 약 **1.43:1** (예: 2388×1668, 1668×1194)
3. 같은 화면에서 모니터 위치(노트북 오른쪽/왼쪽)를 끌어서 맞춥니다.

## 2. 실행

1. [Python 3.10+](https://www.python.org/downloads/) 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 이 폴더의 **`start.bat`** 더블클릭
   - 처음에는 필요한 패키지를 자동 설치합니다 (1~2분).
   - Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 누르세요.
3. 창에 표시된 주소(예: `http://192.168.0.10:8765`)를 iPad Safari에서 열거나, QR코드를 iPad 카메라로 찍으세요.
4. (추천) Safari 공유 버튼 → **홈 화면에 추가** 하면 주소창 없이 전체 화면 앱처럼 열립니다.

가상 디스플레이가 있으면 자동으로 그 모니터를 선택합니다. 직접 고르려면:

```bat
start.bat --list          :: 모니터 목록
start.bat --monitor 2     :: 2번 모니터 스트리밍
start.bat --password 1234 :: 비밀번호 설정 → iPad에서 http://IP:8765/?key=1234 로 접속
start.bat --no-input      :: iPad 터치 조작 끄기 (보기 전용)
```

## 3. iPad 조작법

| 동작 | PC 입력 |
|---|---|
| 탭 | 왼쪽 클릭 (두 번 탭 = 더블클릭) |
| 길게 누르기 | 오른쪽 클릭 |
| 한 손가락 드래그 | 끌기 (창 이동, 텍스트 선택) |
| 두 손가락 위/아래·좌/우 | 스크롤 |
| 매직 키보드 트랙패드 | 마우스처럼 동작 |

오른쪽 아래 ⚙︎ 버튼에서 **화질 / FPS / 해상도**를 바꿀 수 있습니다 (iPad에 저장됨).
끊기면 해상도를 1920 또는 1280으로, 화질을 60 정도로 낮춰 보세요.

## 4. .exe 파일로 만들기 (선택)

`build_exe.bat`을 실행하면 `dist\iPadDisplay.exe` 하나로 만들어져 Python 없이 실행할 수 있습니다.

## 문제 해결

- **iPad에서 접속이 안 됨**: PC와 iPad가 같은 Wi-Fi인지, 방화벽에서 Python이 허용됐는지 확인하세요.
  공용 네트워크로 설정된 Wi-Fi면 `설정 → 네트워크 → Wi-Fi 속성`에서 **개인**으로 바꾸세요.
- **터치 위치가 어긋남**: 디스플레이 배율이 달라도 자동 보정되지만, 문제가 있으면 `--list`로 모니터 번호를 확인하세요.
- **관리자 권한 창(작업 관리자 등)이 터치에 반응하지 않음**: Windows 보안 정책 때문이며, `start.bat`을 관리자 권한으로 실행하면 됩니다.
- **지연(딜레이)**: 5GHz Wi-Fi를 사용하면 훨씬 좋아집니다. 이 앱은 JPEG 스트리밍 방식이라 게임/영상보다는 문서·참고자료·메신저 띄우기에 적합합니다.
